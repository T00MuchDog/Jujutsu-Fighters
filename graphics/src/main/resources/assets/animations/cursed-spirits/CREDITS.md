# Cursed Spirit Animation Pack

All 67 transparent sprite sheets in this pack are newly drawn pixel geometry,
composed and timed for JJKTBF. No source-pack cels, recordings, character sprites,
screenshots, or animation databases are copied into these sheets.

Visual references: the user's existing sorcerer animations in `jjktbf-pixel-fx`
and **Gen 3 Move Animation Pack V1.0 by TheTinfoilTemplar**. The latter's supplied
Readme permits using the pack as a template/foundation and requests optional
credit, which is retained here. Its third-party rights are unchanged; that reuse
permission is not a blanket commercial clearance for other intellectual property.

The source library was inspected at this machine's equivalent of the supplied
Animations directory. No original library assets were modified.

Artwork source, timing, and reproducible exporter are included in this repository:
`scripts/animation_art/cursed_spirits.json` and
`scripts/build_cursed_spirit_animations.py`. New material is supplied for use and
modification within the user's JJKTBF project under its existing project terms.
No ownership of Jujutsu Kaisen names, characters, or other third-party IP is claimed.
