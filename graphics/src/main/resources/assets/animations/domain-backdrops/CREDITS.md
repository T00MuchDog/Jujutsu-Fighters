# Self-Embodiment of Perfection backdrop

Original artwork generated offline by `scripts/build_domain_backdrop.py`.
The script uses deterministic Pillow polygon, ellipse, line, and blur passes;
no external image assets or generative services are used.

- Canvas: 1920x1080 RGBA PNG, fully opaque
- Seed: `0x5E1F0F`
- Subject: cel-shaded slate-violet arms, stitched seams, and repeated hands
  gripping the next forearm in a near-black aubergine void
- Regeneration: `python3 scripts/build_domain_backdrop.py`
