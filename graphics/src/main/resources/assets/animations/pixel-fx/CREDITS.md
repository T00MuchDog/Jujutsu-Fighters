# Credits And Provenance

## Supplied Source Pack

**Gen 3 Move Animation Pack V1.0 by TheTinfoilTemplar.**

The supplied `Readme.pdf` explicitly says credit is appreciated but not required,
and that users are free to use the pack as a template or foundation for their
own animation resource. Credit is retained here and in the preview.

The custom effects use selected cropped, nearest-resampled, recolored cel
fragments from the supplied pack, composed with newly authored pixel geometry
and new timing. `sourceGraphics` in each manifest entry lists the PNGs actually
used for that effect. Empty source lists mean the effect uses new geometry only,
with the pack serving as a visual reference.

The Essentials Ruby animation databases, original timelines, and original OGG
recordings are not redistributed as part of this generated pack. No official
Nintendo, Game Freak, or Pokemon affiliation is claimed. The source README's
reuse permission is not a blanket clearance for all third-party IP or commercial
distribution; retain the original documentation and review rights for release.

## Preview Characters

`preview/assets/yuji.png` and `preview/assets/megumi.png` are copied from the
user's existing JJKTBF character assets solely to review effects in context.
Their authorship and rights are unchanged. They are not included in the exported
effect sprite sheets and are not newly authored character art.

## New Material

The physical-attack pass uses the user's visual references for shape, palette,
and motion direction. The screenshots themselves are not redistributed or cropped
into the new sprite sheets; the fist, footprint, white ring, and energy coating
are newly drawn pixel geometry.

- Mach Punch, Generation III: https://archives.bulbagarden.net/media/upload/7/79/Mach_Punch_III.png
- Sky Uppercut, HGSS: https://archives.bulbagarden.net/media/upload/3/37/Sky_Uppercut_HGSS.png
- Double Kick, Generation IV: https://archives.bulbagarden.net/media/upload/1/11/Double_Kick_IV.png

Reference screenshots are from Pokemon games, hosted by Bulbagarden Archives.
The supplied Comet Punch and Double Kick cels were also inspected as visual
references; the new physical sheets do not copy their pixels.

The full Sorcerer pass adds 23 newly drawn sequences for guards, weapons,
movement and utility actions. These use original pixel geometry and existing
pack palettes/primitives; `sourceGraphics` remains empty for those new sequences.
JJKTBF's current move JSON is read only to establish category scope, names,
reinforcement eligibility, targeting intent and hit-count reference metadata.

Effect choreography, additional pixel geometry, palette treatments, original
synthesized WAV cues, preview courtyard/UI, generator, and integration adapter
were created for this task. The audio uses deterministic synthesis, not samples
from the supplied recordings.

Jujutsu Kaisen names and character references are used as context for the user's
existing fan-game project. This resource is unofficial.
